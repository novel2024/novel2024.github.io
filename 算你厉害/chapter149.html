第149章 普尔曼

1月7日。

玄武门那栋一千两百平米的独栋办公楼里，二楼的会客室很安静。

许亚波坐在沙发上，双手放在一台笔记本电脑的键盘上，眼睛看着屏幕上的代码编辑器窗口。他按下了一个快捷键，屏幕侧边的分析框里迅速跳出几段文字提示，下面跟着四种不同的架构修改方案。

他移动鼠标，把这四种方案从头到尾仔细看了一遍，然后把笔记本电脑合上，放在面前的茶几上。

许亚波抬起头，看着坐在对面的叶冬青。

“这一个星期，我每天都在试这个新模块。”许亚波的语气里带着明显的兴奋，“之前那个‘一指禅’，我以为只是个能提高写代码速度的辅助工具。但现在加了这个‘元芳’进去，这东西的性质完全变了。”

他拍了拍电脑外壳。

“高级程序员在处理底层冲突或者复杂业务并发的时候，个人的思维是有局限性的。”许亚波说得很专业，“但这个工具不一样。它能搜索极其庞大的概率空间，不仅能把你的思路理顺，还能提供相当广泛且具备多样性的建议。有些解决方案，就算是经验最老道的架构师，不花上几天时间去查资料，根本想不出来。”

叶冬青靠在沙发背上，端起手边的水杯喝了一口。

“这只是它目前能做到的一小部分。”叶冬青放下水杯，语气平稳，“随着喂给它的代码库越来越多，它给出的建议会越来越精准。”

许亚波点点头，身体往前倾了一些。

“叶总，产品已经成熟到这个地步了，是不是该准备开始公测了？”许亚波问道。

“是准备公测了。”叶冬青看着他，“不过，不是以现在的名义。”

许亚波稍微愣了一下：“不以现在的名义？您的意思是？”

“这款产品从第一天开始，就是为了全球市场准备的。”叶冬青把自己的构想直接摆在了桌面上，“如果顶着国内初创公司的帽子去推，会遇到很多技术信任和地域上的壁垒。我们换个壳子。”

他伸出一根手指，在茶几上点了一下。

“在硅谷注册一家新公司。名字叫‘Pullman Code Agent’。我们的产品就叫 Pullman。”叶冬青说。

“Pullman？”许亚波重复了一遍这个名字。

“来源于程序员常用的代码合并指令 Pull Request。”叶冬青解释道，“这名字符合国外极客的命名习惯。包装成一个纯粹的硅谷本土初创项目发布，所有的服务器节点和数据交互全都挂在海外。外界只会把它当成一个横空出世的硅谷高科技产品。”

他把国内的安排也顺带提了一嘴。

“至于国内的公测，只切出一小部分接口来跑一跑数据。”叶冬青说，“除了我们核心团队的这几个人，没有任何人会知道‘八荒六合’就是 Pullman 背后的公司。两边在物理和商业层面上做绝对的隔离。”

对于叶冬青来说，这种做法是最省事的。不用去应对国内那些繁琐的软件备案和同行之间无休止的打听，直接在拥有最大付费意愿的市场上建立标准，这是效率最高的变现方式。而且，既然未来的目标是实现完全自主的编程系统，提前在硅谷稳住阵脚，就是拿到了最核心的话语权。

许亚波听完这套方案，眼睛立刻亮了起来。

风投机构最看重什么？最看重的就是全球化叙事和硅谷光环。一个能在硅谷本土引起轰动的技术工具，在资本市场上的估值逻辑和国内一个做辅助软件的公司是截然不同的。

“这个思路绝对没问题。”许亚波拍了拍胸脯，直接把任务揽了下来，“海外公司的注册、股权架构的平移映射，以及前期的各种法务合规手续，全都交给我去办。红杉在硅谷那边的资源很丰富，只要公司落地，向硅谷各大编程社区推广的任务，我保证安排得明明白白。”

叶冬青笑了笑。

“其实推广没什么难度。”叶冬青看着许亚波，“只要找人在 Hacker News 上发个帖子，简单介绍一下这东西怎么把高级程序员的活儿给干了，再放几个试用链接。那些国外的技术极客自己就会凑上来。流量这东西，在绝对的技术压制面前，自然会爆开的。”

他把以后的盈利模式也定了下来。

“等用户基数起来了，我们不卖软件拷贝。”叶冬青语气十分随意，“直接开放付费 API。按调用次数和生成的 Token 数量收钱。那些科技巨头和外包公司为了提高开发效率，会乖乖把钱打进我们的账户里。”

许亚波坐在椅子上，听着这个清晰的商业闭环，双手在膝盖上搓了两下。

这才是真正的一本万利。不需要庞大的销售团队去线下推销，只要把计算接口一开，全球的程序员每天敲击键盘的时候，都是在给这家公司交过路费。

“叶总。”许亚波的呼吸变得有些急促，“只要这套付费 API 跑通，我们拿到第一桶金和首月的订阅营收数据，立刻就可以启动第二轮融资。”

许亚波给出了他的专业判断。

“带着在硅谷社区的统治级口碑，再加上实打实的全球现金流。第二轮融资，我有把握让红杉牵头，把公司的估值直接飙升十倍以上。”

十倍。

从上一轮的十亿美元，直接跳到一百亿美元。

这在投资圈里，是一个足以写进教科书的飞跃。

叶冬青坐在沙发上，听着许亚波抛出的这个数字，脸上没有出现任何狂热的表情。一百亿美元的估值固然是个好听的数字，但对他来说，只有实实在在落进账户里的 API 费用才是最舒服的进账。

“行。”叶冬青没有在这个估值上多做停留，他站起身，“你先去把硅谷那边的公司手续弄好。需要哪些底层的证明文件，让财务配合你。”

他转过头，看着通往楼下办公区的门。

“我去安排他们把 Pullman 的初始版本代码打包，把接入海外节点的服务器搭建好。随时准备上线。”

许亚波跟着站起来，拿起茶几上的笔记本电脑装进公文包里。他现在干劲十足，拿到这个全球化的布局任务后，他得立刻赶回京城总部，去协调硅谷那边的落地事宜。

两人在二楼会客室门口简单道了个别。

许亚波快步走下楼梯离开了大楼。叶冬青转身走进了旁边那间挂着“恶人谷”牌子的核心会议室，准备让王浩和陈卓把手里的测试停一下，开始切入到全球公测的发版准备中去。
